# Agent 自主执行增强实施计划

日期：2026-09-21。用户已授权本地开发；虚拟机待用户提供后再测试，禁止上传。

目标：在已有 14 个工具及 SRE 技能基础上形成计划、执行、纠错、验证流程。沿用现有 SSH、TaskManager 和权限模型；不重写调度器，不承诺任意变更自动回滚。

1. tests/agent-execution.test.ts 先验证工具参数、权限和完成判据；实现 agent-execution.ts（动作模板、计划结构与验证逻辑）。
2. 扩展 agent-contract/shared agent：计划更新元工具、service_action、compose_action、verify_service。只读状态查询/配置校验与修改动作分离；修改动作走已有任务管理和审批。
3. agent.ts 保存计划与检查点，向模型提供持久化进度及失败证据；新 SSH 执行任务必须先有计划与前置观测，修改后必须有新验证；重复失败自动暂停，状态不明不重放。
4. sre-skills.ts 增加应用搭建部署、故障修复技能；AI.tsx 展示计划进度及验收结果。保留原权限及历史兼容。
5. 完成单元/会话集成/界面测试，独立复查并修复；记录指南及项目进程，不打包上传。

验收：自主模式能规划→修改→验证→交付；确认模式仍逐项审批写入，只读不能借动作参数绕过；没有验证的完成请求被纠正；重复确定性失败暂停；重启/断线未知状态不盲重试；用户停止/暂停继续可用。
