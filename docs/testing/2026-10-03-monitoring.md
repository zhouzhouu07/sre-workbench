## 已证明的缺口与修复

1. 实际产品 Bash 控制流在 Grafana HTTP200/database=failed 时仍 exit0。修复检查 database=ok、Exporter node_uname_info；Compose完成后对四组件逐项重检，日志保存 ready/unavailable，失败非零退出。指标管道读取完整输出，避免早退 SIGPIPE 误判。
2. 实例归属正确但 Grafana 不健康时仍进入建隧道。新增访问前健康门槛。SSH 转发被拒绝时，旧入口仍返回本地 URL；新增打开浏览器前通过本机端口的真实转发探测，限时5秒，失败关闭资源与缓存。
3. 测试告警只返回提交结果，没有读静默状态。提交后只读查询 SREWorkbenchTest，区分 active/suppressed/pending，说明 groupWait、未验证SMTP/收件；查询失败不重发，不撤销静默。
4. 编辑方案一律显示自定义SMTP，设置默认折叠、账号与授权码解释不足。仅在服务器和登录名匹配时识别预设，特殊用户名保留自定义；展开自定义字段，说明发送/接收账号可相同、QQ/163客户端授权码与固定TLS策略。留空保留凭据、显式替换、快照与日志脱敏有回归。

未增加自动端口接管或重新检测按钮：现有访问通过远端标签与精确映射判断，不依赖不存在的本地 deployState。保留 SSH 指纹、TLS、端口归属边界。
