# AI 协议与会话界面验收（v0.2.1）

## 故障证据与修复

用户在 DeepSeek Anthropic 兼容接口、`deepseek-flash` 模型上请求查看服务器安装环境，连续三次格式拒绝；历史两条为纠正记录，没有执行主机工具。

同协议只调用模型复现 HTTP 200 / end_turn，但返回两个连续 JSON 对象；加强提示后仍可出现 JSON 后附带 DSML 工具标记。仅修改提示词不能可靠解决。任务步骤现改用 Anthropic 原生 `submit_step`，只接收一个 tool_use.input，拒绝多调用，并经过原有工具参数和权限校验。指定 tool_choice 与默认思考模式冲突的 HTTP 400 已通过显式关闭该请求的思考模式解决。OpenAI JSON 输出路径及脚本兼容入口保留。

错误反馈区分 JSON 语法与具体字段校验，不记录原始模型秘密内容。两个独立 JSON、无效工具参数、原生调用及并行调用拒绝均有回归。

## 会话界面

- 左侧配置模型、已信任服务器和权限，下方显示可命名的对话历史；右侧发送需求、展示逐步执行、审批和输出。
- 移除 Windows 本机/SSH 切换和本机目录选择；旧记录仍保留。底层本机兼容代码用于历史与回归，界面不提供本机新建/续作。
- 暂停等待当前操作结束后停止后续步骤；继续沿用上下文，不重放已完成工具。待审批操作暂停后原审批失效。停止仍会尝试中止当前任务。
- 运行中重命名不会被后续状态保存覆盖；每轮助手最终回复持久化，继续对话不会覆盖历史答案。
- 新远端任务标记 AI 来源；旧会话关联任务启动时补标。任务中心隐藏 AI 记录，但会话内保留日志、核实与终止入口，不删除底层任务。

## 实际验证

- DeepSeek Anthropic / deepseek-flash：在已授权 Rocky 主机以 root、`/`、sudo 配置完成 6 步环境盘点，正常结束。仅查询系统、运行时、服务和容器状态，未安装/修改配置/停止业务。
- 类型检查、生产构建通过；129 项单元测试通过。
- 6 项 Electron 回归通过，包含服务器聊天发送/暂停/继续/追加消息、重命名、精确审批、任务来源过滤及既有部署/监控流程。
- 截图检查布局与输入区，证据保存在忽略目录 `test-results/`；真实模型任务记录保存在 `.tools/inspect-live/`，不纳入 Git。
- 代码审查发现旧本机会话恢复缺少其他未知任务防护，补充回归后修复，审查已确认关闭。

打包/上传的最终结果见根目录 `项目进程.md`。凭据不写入项目记录。Windows 覆盖升级与其他 Linux 发行版未新增验收。
