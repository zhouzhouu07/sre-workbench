## 手动验收

| 场景 | 预期结果 |
| --- | --- |
| 分析建议 | 只输出建议；即使模型要求工具，也被后端拒绝 |
| 只读诊断 | 可读取选定目录/固定系统信息；写文件和任意命令被拒绝 |
| 确认执行 | 展示准确路径、文件内容/命令，确认前不变更；拒绝不执行；确认不能重复使用 |
| 自主执行 | 多次工具调用实际生成文件、运行并读取结果；遇到可处理错误后能修正 |
| 更换参数 | 界面不能替换待审批调用；会话不能自行换主机、权限或 sudo |
| 路径边界 | `../`、同名前缀目录、越界符号链接被文件工具拒绝 |
| 实际终端权限 | 明确显示命令不是目录沙箱，本机使用运行软件的账号，远端使用选定账号/sudo |
| 停止任务 | 模型请求或当前命令停止，后续步骤不执行；保留已有变更记录 |
| 断线/重启 | 未知远端状态或重启中断记录需核实，不自动重放 |
| 超时/超量 | 模型超时、命令超时、输出和步骤达到上限均有反馈 |
| 模型兼容 | 真实 OpenAI 兼容和 Anthropic 兼容接口分别验证多轮 JSON 工具响应 |
| 既有功能 | 脚本助手、部署、监控修复及原有回归不退化 |

下面保留后续扩展验收建议：

1. Windows：选择空测试目录，要求生成 Python/Flask + Nginx 项目、模板、依赖和 README。检查文件内容，再按目标机器实际具备的环境启动。缺少 Docker/Python 等条件时应明确提问或安装计划，不能虚报服务运行。
