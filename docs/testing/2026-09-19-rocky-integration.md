# Rocky Linux 9.4 实机联调记录

测试日期：2026-09-17 至 2026-09-19。测试对象为 v0.1.1 之后、纳入 v0.1.2 的修订；v0.1.1 安装包不包含本轮修复。

## 环境与方法

Windows 桌面开发环境连接一台已做快照的 Rocky Linux 9.4 x86_64 虚拟机。约 1.7 GiB 内存、2 GiB swap，初始根分区约 16 GiB 可用。SELinux 保持 Enforcing，firewalld 保持运行。Docker 使用项目安装脚本，从官方 RHEL 软件源安装 Docker CE 29.8.1、Compose 5.5.1。系统依赖按已配置的 Rocky 软件源更新，没有整机升级操作。

远端集成使用实际 Backend、SSHManager、TaskManager 和 FeatureService，经真实 SSH/SFTP 执行；不以替身替代远端命令。界面回归使用独立临时数据目录和受控 IPC，单独验证按钮、预检与反馈行为。测试凭据不纳入仓库。AI 请求仅发送固定探测短句和只读脚本生成要求，没有发送主机日志。

## 本轮修复

1. 新增部署/回退前的只读环境检查与检查结果表，阻塞项禁止执行，正式运行前后端再次检查。
2. 远端作业的输出收集改为无缓冲，短日志不必等进程结束才能显示；仍保留输出上限和原始退出码。
3. 监控 API 先解析 JSON，再对字符串值脱敏，防止短凭据破坏数字或 JSON 语法。
4. AI 结果丢弃模型附加的顶层元数据，仍严格验证脚本字段，附加字段不会变成执行权限。
5. Docker 启动时同时启用开机自启，修复虚拟机重启后应用没有恢复的问题。
