## 查看博客

客户端直连 `http://10.3.128.3:18086/` 实测超时；本轮没有修改防火墙。可在本机终端启动：

```powershell
ssh -N -L 18086:127.0.0.1:18086 root@10.3.128.3
```

使用已有SSH凭据登录，保持终端运行，再打开 `http://127.0.0.1:18086/`。本地18086被占用时可将命令第一个18086改为其他空闲端口，浏览器对应修改。
