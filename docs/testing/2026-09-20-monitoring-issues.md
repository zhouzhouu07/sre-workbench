- Node Exporter 使用共享项目名 `sre-node-exporter`，因此采集器安装成功不代表另一监控方案能够占用已有监控端口。

## 分析

此前测试覆盖健康检查与 SSH 隧道 HTTP 访问，没有覆盖浏览器账号登录，也没有覆盖用户新建方案与遗留测试实例的冲突。测试遗留服务占用共享虚拟机资源需要明确交接。
