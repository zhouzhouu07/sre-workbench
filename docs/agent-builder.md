# Agent Builder

入口：Agent Studio → Agents。内置Linux巡检、Web服务诊断、应用部署、Compose运维四个定义模板，执行统一使用Skill、Tool Registry与现有Agent Runtime。模板需要先编辑绑定已有模型API配置，可克隆后调整。配置不保存API Key；导出只包含定义与模型配置ID。

可编辑名称、描述、图标、分类、模型引用、权限上限、风险策略、Tool白名单、Skill绑定、目标服务器范围、工作目录前缀、步骤/时间上限和验收标准。每次保存递增版本，使用摘要检查并发编辑。系统模板可禁用不能删除；自定义定义可删除，历史会话快照保留。导入JSON使用原生文件选择器，严格校验后生成新ID并默认禁用；跨设备模型/服务器引用需要存在于本机。

运行选择已验证指纹的SSH服务器，权限不能超过Agent上限。Skill的必需工具必须在白名单且启用。服务器范围为空表示本机已配置并验证的全部服务器。工作目录前缀只约束任务入口，不是任意终端命令的沙箱。外部HTTP Agent不是模型API，不可绑定。

运行产生独立快照：Agent版本、Skill说明与验收、Tool版本和摘要、风险策略、无密钥模型信息、目标、权限、开始与截止时间。修改或删除定义不影响在途任务；禁用具体Tool仍阻断下一次调用。模型/主机配置被替换时原安全身份校验会停止任务，避免切换到新目标。

步骤上限约束本次运行总工具调用数；时间上限包括暂停/审批时间，重启不会重置截止时间。超时停止后续调度，已提交远端作业使用既有核实流程，不声称已回滚。谨慎策略要求所有变更审批，均衡策略要求高风险变更审批，自主策略仍遵守权限上限和工具包审批规则。后续Risk Engine统一细化评分。

普通运行的输出、命名、暂停/继续、审批和恢复在AI助手会话中查看。绑定默认Workflow后，运行入口转到流程引擎，在Workflows执行记录查看；缺少输入时在流程记录补充。父Agent的目标、权限、Tool白名单和截止时间继续约束整个流程；子Agent不得调用超出父白名单的工具。
