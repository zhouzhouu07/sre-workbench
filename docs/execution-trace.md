# Execution Trace

Agent Studio → Runs统一查看Agent与Workflow执行。时间线来自已落盘的会话步骤、风险/审批、计划、独立验收、工作流节点事件、恢复记录和模型用量，按时间合并。Workflow同时包含子Agent事件，并可跳转子记录。不另造与执行状态脱节的“演示日志”。

版本区显示Agent、Skill、Tool、Workflow快照及目标/权限。旧会话缺少版本信息时标记legacy，不补造历史版本。模型统计只记录接口请求次数、状态、模型名和接口提供的token用量；不保存原始模型响应、隐藏思维链或认证头。接口未提供完整用量显示null，不用字符数估算冒充实测token。

支持通过原生保存对话框导出JSON/Markdown，导出再次过滤已知凭据和敏感字段。包含结构化证据及子Agent引用，可供竞赛附件使用。导出记录未证明主机结果正确，需同时查看实际Verify和后续Benchmark独立验收。

指标口径：工具请求包含模型/工作流提出的结构化调用（包括拒绝请求）；失败记录实际失败状态，工作流保留重试前失败；模型调用只计实际进入模型接口请求路径的记录。人工审批和补充输入单独记录；恢复核实次数不等于成功率，resumeSuccesses只在继续后整体完成时计入。旧数据没有采集的指标保留缺失事实，不补造。

2026-10-02 本地未发布增量：Runs 改为紧凑事件表，显示时间、工具/类型、摘要、状态、实测耗时、风险和 Evidence ID；搜索工具/摘要/ID、按事件类型过滤，展开查看完整已保存参数、输出与作业引用。切换记录时显示加载状态并使旧请求失效，错误可刷新重试。Evidence ID 是记录引用，只有成功且已核实的观测才可作为完成验收；待核实结果不展示为成功。

新增事件字段均为可选，JSON schemaVersion 仍为 1。耗时只在有实际起止时间时计算；旧记录缺少状态/耗时显示空缺。新的 Workflow 完成/失败事件保存当次 call/status/起止/输出/risk，重试后不以最终节点状态覆盖先前事件。旧事件不补造输入、风险或耗时。固定版本和原始结构化证据继续保留，导出仍走原生保存与脱敏入口。
