## 第二批：AI 权限分级与任务执行

### 用户明确要求

- AI 模块加入权限程度选择，除其他权限档位外，最高权限允许操作电脑。
- 用户给出需求后，AI 严格按需求执行，而不只是生成文字建议。
- 后续深化自定义工作流、搭建 Agent、导入 Skill 等能力，以支持比赛展示。

### 待设计的权限方案（建议，尚未定稿）

| 候选档位 | 候选能力范围 |
| --- | --- |
| 分析建议 | 对话、分析用户提供的上下文，不操作系统 |
| 只读诊断 | 在选定范围读取状态、日志、文件；不变更业务配置 |
| 确认后执行 | 生成变更方案和命令，由用户确认后调用工具 |
| 范围内自主执行 | 在指定主机、目录和工具权限内完成多步骤任务，展示进度与验证结果 |
| 电脑操作 | 支持用户授权范围内的本地终端、文件，以及浏览器/桌面操作；具体平台和技术路线待确认 |

“操作电脑”究竟包含 Windows 本机、远端 Linux、浏览器还是完整桌面，需要下一轮明确。不能将现有 SSH 执行能力等同于本机桌面控制。

权限应由工具执行层校验，不能仅靠提示词；模型回复、导入的 Skill 或外部文档不能自行提升权限。高权限仍受用户任务范围约束。需要可见的当前权限、执行记录、中止入口、超时及失败反馈；具体逐步确认规则和危险操作边界后续与用户确定，避免每个普通操作都反复确认。

验收方向：不同权限档位下相同工具调用得到正确允许/拒绝结果；无法越权；任务执行可中止；实际完成情况可验证；失败和部分完成如实呈现。不得把“严格遵循需求”宣传成模型永不出错的保证。
