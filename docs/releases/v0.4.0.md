# SRE Workbench v0.4.0

本版将现有 SSH 运维平台升级为 SRE Agent Studio，保留主机管理、应用部署、监控告警和 AI 会话。

## Agent Studio

- Tool Registry / Tool Center：21 项内置工具、受控 Remote Script／回环 HTTP 包、Schema、版本摘要、启停及调用记录。
- Skill Package / Skill Center：4 项内置 SRE 技能、包导入／升级、工具依赖和固定运行快照。
- Agent Builder：自定义 Agent、模型引用、工具白名单、技能、目标范围、权限上限和执行预算。
- Workflow Studio：12 类节点、条件、具体审批、有限重试／等待、子 Agent 与持久检查点。
- Risk Engine：后端风险评分和解释，与原权限取更严格限制；严重风险拒绝。
- Execution Trace / Versioning：工具、风险、审批、验证、恢复和接口实际用量的统一记录，支持 JSON／Markdown 导出。
- Competition Benchmark：12 个隔离场景，A/B/C 对照、真实故障注入、独立远端验收及 JSON／CSV／Markdown 导出。

## Reliability

- Persistent Task 与 Resume / Recovery 核实原 Task，未知变更不自动重放；完成的操作不因继续而重复提交。
- 每轮提供真实 Evidence 索引、锁定验收项状态与可引用 ID；模型仍需提交由后端核验的完成证据。
- `verify_file` 1.1.1 支持严格 `{path,exists:false}`，悬空链接视为存在，仅 `FileNotFoundError` 可判缺失；保留 symlink／`..` 实际路径语义，权限拒绝不能误报成功。
- `update_plan` 1.1.0；运行固定 Tool／Skill 版本，不静默替换旧执行器。服务／HTTP 独立验收及首次变更后的 checks 锁定继续强制执行。
- 修复恢复审批、导入工具恢复数据、`/dev/null` 诊断误拦截、短数字断言脱敏碰撞和计划验收路径预检等实测问题。
- 发行审查补齐 Risk 1.0.2 相对路径评分和远端 realpath 后关键路径拒绝；`write_file`／`make_directory` 升级 1.0.1。失败／取消子 Agent 的工具调用统一累计父预算，检查点避免重复计数；导入工具恢复的结构化数据与正常结果逐字段脱敏，避免泄漏或破坏 JSON。旧版本实验保持原口径，不将其冒充 1.0.2 的实机得分。

## Benchmark

真实 Rocky Linux 9.4、DeepSeek `deepseek-flash` / Anthropic 实验，从逐例 JSON 重新核对统计：

| 指标 | A 通用 Agent | B SRE Skill | C Studio |
|---|---:|---:|---:|
| 36 个非接口阻塞案例，成功/评估 | 10/12 | 8/12 | 10/12 |
| 恢复场景成功 | 3/4 | 3/4 | 4/4 |
| 误报成功 | 0 | 0 | 0 |
| 独立定向可靠性实验，成功/评估 | 2/4 | 4/4 | 4/4 |
| 最终 1.1.1 超时核实 Agent 步骤 | 10 | 11 | 8 |

最终三组超时核实通过：`count.txt=1`、结果文件不存在、各自只有一个执行 Task，无重复执行。核实预期超时不等于业务脚本执行成功。

36 例采用固定选取规则：补测场景 1–5 + 原实验场景 6–12，保留原 13 个 HTTP402 接口阻塞和失败记录；不按最好结果筛选。定向 12 例与最终 3 例独立记录，不混入旧统计。每场景每模式样本有限，模型有随机性，不具统计显著性，不能宣称 Studio 总体成功率稳定优于通用 Agent。

三个真实 Demo：Web 自愈成功；Compose 部署／修复成功（修复含一次人工续接）；后台进程重启后的子 Agent 恢复成功，执行计数为 1。完整证据与限制见 [实测报告](../testing/competition-agent-benchmark.md)。

发行审查修复后重新执行：23 个文件、238 项单元测试通过，14 项 Electron 回归通过，typecheck 与 production build 通过。比上轮 231 项新增 7 项安全／恢复回归；没有删除或跳过失败用例。最终只读审查未发现剩余 P1/P2，独立复跑 4 文件 57 项通过。安装包启动和发行附件验证记录另见 [发布验收报告](../testing/2026-10-01-v0.4.0-release.md)。

## Known Limitations

- 通用 Agent 仍可能生成与实际产物不一致的验收项，造成自主收尾失败；严格验收不会因此放宽。
- 模型具有随机性，Benchmark 每场景样本数量有限；模型总结不能替代 Tool Evidence。
- 任意 Shell 不是文件系统沙箱，规则型 Risk 也不是操作系统隔离。
- 不提供通用事务回滚；停止操作不能撤销已完成变更。
- 实机证据主要来自 Rocky Linux 9.4，尚未验证所有 Linux 发行版；DEB 分类验收仍待实机覆盖。
- 后台进程重启恢复已测，Windows 重启、完整 Electron 重开、VM 掉电组合及 Windows 覆盖升级未完整验收。
- 不含 Kubernetes、多租户、MCP／在线插件市场、通用桌面／浏览器控制；移动端尚未实现。
- 无商业代码签名，构建保留既有前端大分块提示。
