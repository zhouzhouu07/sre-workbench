# SRE Workbench v0.2.0

新增可以实际执行任务的 AI 助手。用户选择 Windows 本机或 SSH Linux 目标及执行权限后，助手可检查环境、生成项目、运行命令、读取错误并修正、验证 HTTP 结果。保留原脚本助手兼容入口。本版同时包含上一轮尚未打包的监控修复。

## 功能与修复

- 分析建议、只读诊断、确认执行、自主执行四档权限，后端校验每次工具调用；审批显示准确文件内容或命令。
- 支持停止、追问续作、历史记录、重启后核实未知任务；不自动重放中断操作。
- 本机文件工具检查符号链接和目录边界，命令使用当前账号权限；命令执行不是目录沙箱。
- OpenAI 兼容任务模式使用 JSON 输出并对格式错误有限纠正；模型不能修改会话权限或目标。
- 改进短凭据脱敏，保护密码上下文并保留正常 IP、路径和源码数字。
- 监控支持自定义 Grafana 初始用户名、三个管理端口、实例归属核验及端口冲突检查；保存配置时关闭旧隧道。旧 Grafana 密码不会自动重置。

## 验证与边界

Rocky Linux 9.4 实测：DeepSeek 通过软件 AI 服务自主部署 Python + Flask + Gunicorn + Nginx 简洁博客，遇到镜像连接和 Python 语法错误后读取反馈修正，首页、两篇文章、样式与健康检查返回 200。独立浏览器检查通过，原有 14 个容器清单保持一致，旧 Node 服务返回 200。

自动化测试及打包验收详见 [AI 验收记录](../testing/2026-09-20-ai-agent-acceptance.md)。本轮真实自主部署使用 OpenAI 兼容协议；Anthropic 兼容接口已验证连通，未单独进行多轮部署验收。

尚未包含自定义 Agent、工作流、Skill 工作台及桌面/浏览器自动点击。Windows 覆盖升级与其他 Linux 发行版需进一步验证。安装包未配置商业代码签名。
