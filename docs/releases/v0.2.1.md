# SRE Workbench v0.2.1

修复 DeepSeek Anthropic 兼容模型在环境检查任务中连续输出多个 JSON 或附加 DSML 标记导致的格式失败，并将 AI 助手改为服务器专用对话界面。

- Anthropic 任务使用原生单个结构化工具调用；参数与权限仍严格校验。错误提示区分 JSON 语法和具体字段问题。
- 左侧上方配置模型、服务器、权限，下方为可命名的对话历史；右侧发送指令、查看执行与结果。
- 移除 Windows 本机/SSH 环境切换，直接选择已检测并信任的远程服务器。
- 新增暂停和继续；当前操作结束后暂停后续步骤，保留结果，不自动重放已完成命令。停止功能继续保留。
- AI 关联记录从任务中心移至 AI 会话内，支持查看日志、核实和终止远端操作，旧记录自动归类。

实测 DeepSeek `deepseek-flash` / Anthropic 接口完成 Rocky Linux 环境盘点，6 步正常结束，仅查询系统、软件版本与服务状态。原有博客保留运行。

下载 `SRE.Workbench.Setup.0.2.1.exe`，退出旧版后安装；凭据和历史数据保留。校验值见 `SHA256SUMS.txt`。安装包未配置商业代码签名；Windows 覆盖升级未单独验收。
