# SRE Workbench v0.4.1

2026-10-06 桌面正式发行，基于 v0.4.0 的监控、Workflow／Trace稳定性和界面改进。采用2026-10-03已构建验收的Windows x64 NSIS安装包；本轮按用户指示直接发行，不重复回归或重编译。101项原构建输入与当前产品源码一致。Android工程不包含在桌面发行中。

## 修复与改进

- 监控部署逐项核验 Grafana 数据库、Prometheus、Alertmanager 和 Exporter，业务健康失败不再显示部署成功。
- 打开监控前核验健康状态并探测真实 SSH 转发，失败时释放隧道并显示原因，保留方案归属与 SSH 指纹检查。
- 连续点击同一监控入口共享待完成的验证，避免提前打开尚未验证的隧道。
- 建立监控隧道期间保存／删除方案时，中止旧配置的访问并释放资源。
- 测试通知显示告警激活、静默或待确认状态，区分提交、发送与实际收件。
- 邮件配置说明 SMTP 登录账号、收件地址、客户端授权码及 TLS 策略，正确保留预设与自定义配置。
- 修复 Workflow 运行校验期间并发启动及关闭竞态，防止遗留无实际执行的 running 记录。
- 修复 Runs 迟到响应覆盖当前证据，改进错误、加载、重试与导出状态；Trace 保存各次节点实际输入、输出及时间。
- 调整桌面总览、Agent Studio、工具／技能详情与运行上下文，保留现有 Ant Design 桌面工具布局。

## 验证与边界

监控专项已完成真实 Rocky Linux 9.4 隔离部署、重部署账号保留、SSH 转发与浏览器访问；用户确认邮件收件及现场测试全部通过。旧监控与数据卷保留，无新增付费模型实验。

原打包回归为24文件256项单元、17项Electron、typecheck/build通过，实际包内隔离启动18项通过，已知真实凭据扫描0命中；详见 [原打包验收](../testing/2026-10-03-v0.4.1-package.md)。本轮的源码、上传和匿名下载核验见 [正式发行核验](../testing/2026-10-06-v0.4.1-release.md)。包内文档保留10月3日打包时的本地发行状态说明，本页与GitHub Release记录正式发布状态。

原现场端口报错未由取证复现，不编造其根因。既有 Benchmark、失败和人工续接记录保留，不能据此声称新版有更高自主成功率。

安装包无商业代码签名，构建保留既有大分块提示；Windows 覆盖升级与完整重启组合尚未新增验证。
