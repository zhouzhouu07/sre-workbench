# SRE Workbench v0.1.2

本版补齐 Rocky Linux 9.4 实机验证，改进部署前检查、执行反馈和模型结果兼容性。提供 Windows x64 安装包，沿用预发行标记。

## 修复与改进

- 部署及回退前检查系统、权限、基础工具、磁盘、Docker 和端口占用，展示中文检查结果；后端正式执行前再次检查，阻塞项禁止提交。
- 检测其他 Docker 项目发布的端口及 TCP/UDP 占用，允许当前应用正常更新。
- 修复远端短日志缓冲，执行过程中及时显示输出并保留退出码和日志上限。
- Docker 安装时启用开机自启，支持主机重启后恢复应用。
- 修复监控 JSON 在短凭据脱敏时被破坏的问题。
- 兼容 DeepSeek 返回的额外顶层字段，继续严格校验脚本内容。

## 验证

- Rocky Linux 9.4：Node、静态前端、Python、自定义 Dockerfile 实际部署及 HTTP 访问通过。
- 版本回退、失败保护、任务取消与恢复、删除、端口冲突拦截通过。
- Prometheus 实际采集、Alertmanager 测试告警与静默、Grafana 和监控 SSH 隧道访问通过；SELinux 与 firewalld 保持启用。
- DeepSeek OpenAI/Anthropic 两种协议实际接入通过。
- 92 项单元测试、4 项 Electron 回归测试和类型检查通过。

真实 SMTP 送达、阈值告警全链路、跨主机采集、公网证书、其他 Linux 发行版和 Windows 覆盖升级仍待验证。安装包未配置商业代码签名。

## 下载与升级

下载附件 `SRE.Workbench.Setup.0.1.2.exe`，退出旧版后安装；建议先备份应用数据。附件 `SHA256SUMS.txt` 提供校验值。
