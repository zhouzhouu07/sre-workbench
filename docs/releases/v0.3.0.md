# SRE Workbench v0.3.0

增强应用内置 SRE Agent：从主机观测、持久执行计划到部署、故障修复和结果验收，支持远端作业断线核实与会话恢复。

- 内置21项工具、4项SRE技能，覆盖Linux巡检、部署、故障定位和监控诊断；支持systemd/Compose操作及文件备份。
- 计划与执行证据持久保存，支持文件/JSON/Python语法、系统包及服务/HTTP分类验收；变更开始后锁定验收条件。
- 断线后仅退避重查状态，最多连续失败5次，不自动重提变更命令。软件重启后可“核实并恢复会话”，同步远端结果，再从暂停状态继续。
- AI会话显示步骤时间、远端日志、最近核实时间和重试状态；改进目录、Compose参数和验收失败提示。

实测涵盖Rocky Linux上的博客部署、配置修复、客户端查询断线、运行时超时及后端进程重启。Compose改进后自主部署29条步骤、配置故障修复19条步骤完成；首轮验收路径不一致导致的失败也保留在测试记录中。

下载 `SRE.Workbench.Setup.0.3.0.exe`，退出旧版后安装；校验值见 `SHA256SUMS.txt`。本版安装包不携带测试凭据或测试数据库。

已通过164项单元测试、类型检查、生产构建及8项Electron回归；安装包启动验证结果见项目进程记录。

边界：恢复依赖持久作业状态，不支持任意脚本内部逐行续跑或通用事务回滚。模型总结仍可能不准确，关键结果需依据工具证据；Windows覆盖升级、整机掉电恢复未单独验收。安装包未配置商业代码签名。
