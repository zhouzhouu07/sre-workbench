# SRE Workbench v0.1.0

面向 Windows x64 的中文 SRE 自动化运维桌面软件首版，进入实际使用联调阶段。

## 功能

- Linux 主机管理、SSH 指纹确认、加密凭据、多标签终端和 SFTP 文件操作。
- 主机资源概览、进程、systemd 服务、日志和 Docker 容器管理。
- 前端、Node.js、Python 源码部署，HTTPS Git 与本地项目来源，版本记录和回退。
- Prometheus、Grafana、Alertmanager、Node Exporter 集中监控及通知配置。
- 持久任务记录、脚本版本管理、OpenAI 兼容 API 与 HTTP Agent 辅助。
- AI 上下文预览及脱敏，脚本执行前确认。

## 下载与使用

下载 `SRE Workbench Setup 0.1.0.exe` 并安装。普通使用无需自行安装 Node.js、Python 或 Git。远端 Linux 需要开启 SSH，并能访问软件源及镜像仓库。

支持的目标系统：x86_64 Ubuntu 22.04/24.04、Debian 12。详细配置见仓库 `docs/user-guide.md`，Agent 协议见 `docs/agent-api.md`。
