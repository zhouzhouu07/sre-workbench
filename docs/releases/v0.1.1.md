# SRE Workbench v0.1.1

本次补丁版本集中修复现有运维流程，提供 Windows x64 桌面安装包。沿用预发行标记，真实虚拟机联调尚待完成。

## 修复与改进

- 应用部署、监控方案、任务记录和脚本版本增加删除操作。仅清理本地记录及关联配置，不卸载远端服务。未完成、待核实、收尾中或仍被依赖的任务不能删除。
- 脚本、应用与监控任务提交后打开执行反馈，持续显示状态、步骤、日志和退出码。
- 监控表单增加中文字段校验，阻止空采集目标和重复提交；错误提示不再堆叠原始校验 JSON。
- 简化邮箱设置，提供 QQ、163、126 和自定义 SMTP；修正 465 直接 TLS 与其他端口 STARTTLS 的配置，保留自定义免认证中继行为。
- 模型接口支持自动识别、OpenAI 和 Anthropic 兼容协议；修复 DeepSeek `https://api.deepseek.com/anthropic` 地址的请求处理，增加连接测试和明确的错误提示。
- 增加 Rocky Linux 9.4 x86_64 部署适配，使用 DNF 与 Docker 官方 RHEL 软件源；保留 SELinux 和防火墙策略，发现冲突运行时包时提示处理。
- 更新使用说明、接口文档及项目架构博客。

## 下载与升级

下载本发行版附件 `SRE.Workbench.Setup.0.1.1.exe`，退出旧版后安装。`SHA256SUMS.txt` 提供安装包及 blockmap 校验值。

普通使用无需另行安装本地 Node.js、Python 或 Git。个人数据保存在当前 Windows 用户的应用数据目录，升级前可在退出软件后备份整个目录。凭据与 Windows 加密上下文关联，不要将数据库备份上传到公开仓库。

目标 Linux 系统：Rocky Linux 9.4、Ubuntu 22.04/24.04、Debian 12，均为 x86_64。需要 SSH、systemd、相应执行权限，以及访问软件源和镜像仓库的网络条件。
